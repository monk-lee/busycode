# Privacy Policy

BusyCode is a fake AI agent CLI simulator that runs in the browser.

## Data Collection

BusyCode does not intentionally collect, transmit, or sell user data.

The app does not use:

- Accounts or login
- Cookies
- Local storage or session storage
- Browser permission prompts
- Analytics SDKs
- third-party API/provider calls from the browser

## User Input

Text typed into the simulator is kept in the current browser session state only. It is used to change the on-screen fake terminal transcript and is not intentionally sent to MonkLabs or any external provider.

Refreshing the page clears the in-memory simulator state.

## Hosting Logs

BusyCode is served through Cloudflare. Cloudflare may process standard request metadata, such as IP address, user agent, timestamp, and requested URL, to provide hosting, security, and operational services.

## Changes

If BusyCode adds analytics, credential storage, browser permissions, user accounts, API calls, or any persistent storage, this document must be updated before release.
